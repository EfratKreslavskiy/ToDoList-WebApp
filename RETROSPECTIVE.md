# Retrospective

## Questions

- What did you do well? What worked?
My spec file was extremely detailed. I wrote it with ChatGPT by first giving it all of my specifications and telling it to flush out more. 
Then i went over it with claude to make sure it wasn't missing anything, and after that I asked Copilot to go over it as well, before actually implementing my project, so it turned out almost exactly as I wanted. 

- What is one thing you learned from each step of the process: 
    - ADRs: I learned about all of the available technologies, and specifically I had to decide between using React or Vue.

    - SPEC: I learned that for every spec that I think of, there are two more  that I forgot, and that everything needs to be laid out clearly to ensure that AI doesn't hallucinate.

    - Working with Copilot: I was amazed at how it created the project and found it so fascinating. After it was created I asked it to teach me about the project it created and I really learned alot!

    - Testing with Copilot: The instructions given to AI to fix a problem must be very detailed, or else it will just use up lots of credits going through the whole project and looking for the root of a problem that might not even be what you had trouble with.

- What did you learn most from the experience? Which step taught you the most?
I learned how to use an AI agent inside my actual project, and I learned about its strengths and weaknesses - when to use it, and when to use a different method to learn infomation.


- What was the biggest hardship?
I think the most difficult/complex step for me was the research because there are so many technologies out there, and learning about all of them and narrowing down my tools was the most complex part of the project.
